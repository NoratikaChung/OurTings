# OurTings — handoff context

Read README.md first (features, setup, commands). This file records decisions and status.

## Decisions
- PWA (user wrote "RWA"): Vite + React 19 + TS, `vite-plugin-pwa` autoUpdate. Single page, no router (no SPA rewrite needed).
- Backend: Firebase Firestore (Spark/free), chosen over Supabase (pauses idle free projects) and Neon (no realtime, needs API code). Whole `events` collection is subscribed; fine for two people's data.
- Access: user wanted no login. Compromise approved by user: one shared Firebase email/password account (`ourtings@noratikachung.com`); its password is the "secret code", entered once per device. `firestore.rules` admit only that email (any other signed-up account is rejected). The Nora/Anant choice is local only (`localStorage`), used for event ownership, comments and filters.
- Times are floating local strings `yyyy-MM-ddTHH:mm` (both users share a timezone). All-day events span whole days through their end date. Birthdays repeat yearly from the birth year; 29 Feb → 28 Feb in non-leap years. Week starts Monday (`WEEK_STARTS_ON`).
- Event owner = creator (whose calendar it's on). Anyone may edit/delete/comment.
- Device prefs (`localStorage`): `ourtings:user`, `ourtings:theme`, `ourtings:prefs:<user>` = { visible, view }.
- Art: original SVG in `src/art/` for the dark Scenery, WelcomeScene scenery, DialogOrnament and the dark avatars' cavern frame (halo, ring, sparkles) + drawn cloaks (Hornet's is a slim bell, user-requested). User-supplied pictures (originals in `assets/`): welcome Hornet/Knight (`src/art/welcome/`, trimmed + mirrored to face each other); avatars (`src/art/avatar/`: Hornet/Knight mask icons trimmed and laid over the drawn cloaks, Totoro badge cut to its ring, white elf icon; light avatars are the pictures clipped to a circle); light scenery (`src/art/ghibli/`: 720×405 Howl's valley background fitted to the screen height; `--focus` keeps 40% of the picture in view (castle) on tablets/laptops and 85% (snowy mountain + sheep) on screens ≤600px wide, user-requested; blurred copy fills the sides on screens wider than 16:9; CSS mist puffs in % of the picture over its hills, the castle's feet and the sheep's hill; big soft CSS clouds cross the sky every ~3 min, two behind Totoro and two in front of him; Totoro is min(max(33.3vw, 33.3vh), 416px) (about a third of an iPhone's height), scaled 0.75× at the top of his path to 1.15× at the bottom (depth, user-requested; each `scenery-fly` keyframe's scale matches its height), colours softened + slight blur + sky-tinted shadow via CSS filter to blend with the painting, flies a 150 s loop; original SVG grass foreground in the picture's meadow greens, fading in from the top, swaying tufts in two layers, plus 5 sparse pampas reeds that bend in the wind; white elf (brightened + soft glow via CSS filter) walks between the grass layers on a 90 s loop, flipping for the walk back). App icon = user's transparent bunny (`assets/icons/app-icon-bunny.png`) → `public/icon.png` (square, transparent) → `npm run icons`: black background for apple-touch and maskable (iOS can't show transparency; it would render black anyway), transparent for browser/desktop icons. Light theme = Studio Ghibli style (Nora = white elf, Anant = Totoro). Dark theme = Hollow Knight style (Nora = Hornet, Anant = Knight) and is the first-open default.
- CI mirrors `pdf-tools`: GitHub Actions verify; Vercel native Git integration deploys (immediately on push, in parallel with Actions; it does not wait for them). Firestore rules are deployed manually (README step 1.5).
- Repo is private. Vercel Hobby only deploys private-repo commits whose author is the project owner, so this repo's local git config authors commits as `Noratika Chung <101931866+NoratikaChung@users.noreply.github.com>`. Commits authored with the work email (`noratika.chung@k3capitalgroup.com`, linked to GitHub account NoratikaChungK3) are blocked ("Deployment was blocked").
- Firestore emulator port is 8085 (8080 is used by WSL relay on the dev machine).
- Welcome (`src/components/Welcome.tsx`, art in `src/art/WelcomeScene.tsx`): shown on every browser-tab visit, never when installed (`isInstalled()` = display-mode standalone or `navigator.standalone`). Butterfly tap calls `requestInstall()` (saved `beforeinstallprompt`, Chromium only) and reveals page 2 with per-device steps from `platform` in `src/lib/install.ts` (iOS has no install API; iPhone: ··· → Share → View More → Add to Home Screen; menu names checked against Apple/Google/Microsoft help pages, Oct 2026). Hornet whispers only a hint, never the code (the page is public). Tiny × = skip to the app. Knight height 0.92 units vs Hornet 1.45 (user-tuned).
